# Wael GAFSI Portfolio

Simple personal portfolio website in French and English.

## Files

- `index-fr.html`: French version
- `index.html`: English version
- `css/style.css`: custom styles
- `img/`: images for profile, about section, projects, and certificates

## Project

This portfolio presents:

- engineering profile and experience
- technical skills
- project gallery
- certificates
- contact information

## Usage

Open `index-fr.html` or `index.html` in a browser to view the site.
